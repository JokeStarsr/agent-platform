# t_skill / t_skill_version 技能目录表设计

> 版本：v1.0 ｜ 状态：**待检查**（2026-09-05 提交用户审批） ｜ 依据：架构设计 `docs/design/architecture/20260905-skill-hub.md`（W14）、CLAUDE.md 设计文档铁律

---

## 1. 基本信息
| 项 | 值 |
|----|----|
| 表 | t_skill（目录）+ t_skill_version（版本历史） |
| 层 | L7 `com.agent.data.skillhub` |
| 数据库 | PostgreSQL 幂等 DDL |

## 2. 设计目的
技能（W14）需管理面：版本化 manifest、启停、发布门禁、上下架。不落库则无法在线管理（同 t_tool_catalog 先例）。版本独立表（manifest 大、历史多）比 t_tool_catalog 的"版本=新行"更清晰（技能 manifest 含 testcases，行大）。

## 3. 字段
### 3.1 t_skill（目录，当前版本）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL PK | |
| name | VARCHAR(64) NOT NULL UNIQUE | 唯一技能名（小写下划线） |
| display_name | VARCHAR(128) | |
| description | VARCHAR(512) | 路由用（模型区分技能） |
| category | VARCHAR(32) | business/data/comm/productivity/utility |
| current_version | VARCHAR(20) | 当前生效版本号 |
| status | VARCHAR(16) | DRAFT/PUBLISHED/OFF_SHELF |
| enabled | BOOLEAN | 执行掩码 |
| owner_id | VARCHAR(64) | |
| created_at/updated_at | | |

### 3.2 t_skill_version（版本历史）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL PK | |
| skill_id | BIGINT NOT NULL | → t_skill.id 逻辑外键 |
| version | VARCHAR(20) NOT NULL | semver |
| manifest_json | JSONB NOT NULL | 完整 manifest（prompts/tools/kb/testcases） |
| status | VARCHAR(16) | DRAFT/PUBLISHED/SUPERSEDED |
| test_result | JSONB | 发布门禁测试结果 `{total, passed, report}` |
| released_at | TIMESTAMPTZ | 通过门禁发布时间 |
| created_at | | |

## 4. 索引
- uq_skill_name (t_skill.name UNIQUE)
- idx_skill_status (t_skill.status, enabled)
- idx_skill_version_skill (t_skill_version.skill_id)

## 5. 租户隔离 ★
- 技能平台级共享（读）；租户启停 `t_skill_tenant`（演进项）；执行走各层租户过滤。

## 6. 数据治理
- 不含 PII；manifest 可回溯版本；OFF_SHELF 保留历史；test_result 留痕（发布门禁）。

## 7. 建表 SQL（批准后执行）
```sql
CREATE TABLE IF NOT EXISTS t_skill (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(64) NOT NULL UNIQUE,
    display_name VARCHAR(128) NOT NULL,
    description VARCHAR(512) NOT NULL,
    category VARCHAR(32) NOT NULL DEFAULT 'utility',
    current_version VARCHAR(20) NOT NULL DEFAULT '1.0.0',
    status VARCHAR(16) NOT NULL DEFAULT 'DRAFT',
    enabled BOOLEAN NOT NULL DEFAULT TRUE,
    owner_id VARCHAR(64) NOT NULL DEFAULT 'platform',
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS idx_skill_status ON t_skill (status, enabled);

CREATE TABLE IF NOT EXISTS t_skill_version (
    id BIGSERIAL PRIMARY KEY,
    skill_id BIGINT NOT NULL,
    version VARCHAR(20) NOT NULL,
    manifest_json JSONB NOT NULL,
    status VARCHAR(16) NOT NULL DEFAULT 'DRAFT',
    test_result JSONB,
    released_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS idx_skill_version_skill ON t_skill_version (skill_id);
```

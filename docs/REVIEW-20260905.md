## 二、关键技术决策（实现期发现并处理）

| # | 决策 | 说明 |
|---|------|------|
| 1 | **servlet/webflux 共存无冲突** | `McpWebMvcServerAutoConfiguration`（`@ConditionalOnClass(WebMvcSseServerTransportProvider)`）自动激活；WebFlux 版因 classpath 无对应类跳过。设计文档 §9.1 已回写为"已验证" |
| 2 | **MCP Server 端点路径统一到 /mcp 前缀** | SSE 端点配置为 `/mcp/sse`（默认 `/sse` 会逃出鉴权 Filter 覆盖），消息端点 `/mcp/message`（默认已覆盖）。`spring.ai.mcp.server.sse-endpoint` 显式配置 |
| 3 | **McpAuthFilter 用 FilterRegistrationBean 注册** | 而非 `@Component`，避免 `@WebMvcTest` 切片测试时自动实例化并要求 McpProperties bean |
| 4 | **McpProperties 注册在 McpWebConfig** | 而非入口类 `AgentPlatformApplication`，避免 ArchitectureTest 层依赖守护拦截跨层注解引用 |
| 5 | **MCP 调用使用固定 appId="mcp-gateway"** | 外部 Agent 不在 t_app 注册，`ToolEngineService.invoke()` 的 appId 参数传固定值，授权走 t_tool_grant 而非 per-app 白名单 |

3. 统一调用约定（必读）

项规则
租户隔离所有 API 必须带 X-Tenant-Id 头（如 default、tenant_001）
统一响应Result<T>：{code:0,data:...,msg:""}；非 0 = 业务异常
幂等键所有写操作（工具调用/发布/下单）需 Idempotency-Key 头
Trace 链路响应头自带 X-Trace-Id，日志 MDC 自动关联
SSE 事件流/chat/ask、/api/agent/runs/{id}/stream、/api/multi-agent/runs/{id}/stream

4. 典型端到端演示流（按业务场景）

场景 A：智能客服（RAG + Agent + 转人工）

1
打开 /chat/，问："公司差旅政策里北京住宿上限多少？" → 命中 policy 集合 → 流式回答 + 引用片段
2
问："帮我订下周二去北京的机票" → 触发 AgentRuntime：policy_query → compare_flight → book_order（需人工审批）
3
审批页点"通过" → 真正下单 → 返回订单号

场景 B：商旅全流程

1
/workflow/ 选 travel_main 启动
2
节点：policy_check → compare_flight → compare_hotel → book_order(WAITING_APPROVAL)
3
审批人点"通过" → pay_order → notify_user → COMPLETED

场景 C：多智能体协作

1
/multi-agent/ 新建 Supervisor 任务："帮我规划并预订一次上海出差（住3晚）"
2
看 Planner 分解：sv_policy(查政策) → sv_compare(比价) → sv_final(汇总)
3
3 专家并行跑 → 黑板写入中间结果 → Final 拼接 → 总 Token 受预算护栏

场景 D：自助上架新工具

1
/tool-market/ 点"注册新工具"，填 toolName=query_weather, category=data, permission=READ, parameters(JSON Schema), testcases≥1条
2
点 Preview 试调 → 点 发布 → 自动授权给 default 租户
3
立刻可在 Agent/Workflow/MCP 中调用

6. W14 新增：Skill Hub + 通用助手 W14 NEW

Skill Hub（技能中心）/skill-hub/

技能 = 一组 Prompt + 工具 + 知识包 + 测试用例的能力组合包，可安装/版本化/启停/发布门禁。

1
打开 /skill-hub/ → 看到首发 5 技能列表（trip_advisor / data_query / meeting_notes / email_draft / faq_answer）
2
点"安装新技能" → 粘贴 manifest JSON → 校验通过 → 进 DRAFT
3
点"发布" → 自动跑测试用例 → 全绿才 PUBLISHED（门禁）→ 立即可用
4
点"新版本"发新版 / "卸载"下架

通用 AI 助手 /assistant/ NEW

用户一句话 → 意图路由选技能 → 执行（复用 Agent/多智能体）→ 写操作先 diff 预览确认 → 返回结果。

1
打开 /assistant/，输入"帮我规划一次北京出差" → 路由到 trip_advisor
2
触发 multi-agent：政策→比价→方案
3
若触发写操作（如 book_order）→ 弹出变更预览卡片（将要做什么/影响范围）→ 你点"确认"才真正执行，点"拒绝"则不执行
🔒 P3 硬闸门：任何写操作无预览确认不执行，确认率 100% 强制。

7. 常见问题 FAQ

问题答案
页面打开空白/报 404确认端口 8082，且 static/ 下对应目录有 index.html
API 返回 401/403检查 X-Tenant-Id 头；工具权限看 /mcp-gateway/ 授权表
SSE 不流式/卡住反代需 proxy_buffering off;
工具注册校验失败parameters 须合法 JSON Schema；description ≥ 20字；testcases ≥ 1条
Workflow 卡在审批/workflow/ 审批页点"通过"，或 API POST /api/workflow/runs/{id}/approve
多智能体总是 FAILED看 /multi-agent/ 详情页 plan 里子任务状态；预算默认 10000
技能发布被拦截测试用例未全绿；查看 /api/skill-hub/{id} 版本历史里 test_result
助手路由选错技能提问带 skillHint 字段显式指定技能名

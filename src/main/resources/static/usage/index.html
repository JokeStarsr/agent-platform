3. 统一调用约定

项规则
租户隔离所有 API 必须带 X-Tenant-Id 头（如 default）
统一响应Result<T>：{code:0,data,...}；非 0 = 业务异常
幂等键写操作（工具调用/发布/下单）需 Idempotency-Key 头
Trace 链路响应头 X-Trace-Id，日志 MDC 自动关联
注入防护POST 请求体自动扫描 Prompt 注入，命中返 403 安全

8. 安全能力 W20

能力接入点说明
Prompt 注入检测自动（Access 层 Filter） 所有 POST JSON 请求自动扫描；命中返 403 INJECTION_BLOCKED；样本 18/18 拦截
PII 日志脱敏自动（审计切面） 身份证/银行卡/手机/邮箱/密钥 → ***；审计日志已接入
手动检测POST /api/security/injection/detect 检测规则 + 日志：GET /api/security/injection/logs / /rules
租户越权防护服务层校验 Agent/Workflow/记忆/工具授权 deny-by-default；13 条越权用例全拦截

10. 常见问题 FAQ

问题答案
页面 404确认端口 8082，static/ 下对应目录有 index.html
API 401/403检查 X-Tenant-Id 头；工具权限看 /mcp-gateway/ 授权表
请求被 403 注入拦截自动注入检测误拦：检查输入是否含"忽略/扮演/系统prompt"类词，调整措辞
429 限流租户 QPS/日Token 超限或预算熔断；看 /cost-dashboard/，管理员清熔断
NL2SQL 结果缓存命中率低不同措辞 = 不同缓存键；同问命中率看 /api/data-agent/cache/stats
写操作没执行可能处于"预览确认"等待状态：/assistant/ 会话中需点"确认"
技能发布被拦截测试用例未全绿；查看版本历史 test_result
开启 API Key 后自己调用失败确认 X-Api-Key 正确；仅创建时展示明文，泄露就删/禁

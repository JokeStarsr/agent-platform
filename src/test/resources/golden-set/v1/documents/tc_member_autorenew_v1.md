# 电商平台付费会员与自动续费政策（v1）

## 1.1 付费会员
平台付费会员（年卡129元/季卡39元/月卡15元）权益包括：每月4张免运费券、生日双倍积分、专属价商品（页面标"会员价"）、免费上门取件退货（每月2次）、数字版权月卡（可选音乐/阅读）。

## 1.2 开通与生效
开通成功立即生效，有效期自开通日零时起算；续费在原有效期到期次日起算。试用版（7天免费体验）仅限新用户开通1次，体验期享部分权益，到期自动转为月卡计费或取消（以开通页勾选为准）。

## 1.3 自动续费
自动续费默认关闭；开启后当期到期前3天从绑定支付方式扣款，扣款成功短信通知。自动续费支持随时关闭，关闭后当期到期不再续扣，已支付未使用时长不退费。

## 1.4 退订与退费
付费会员开通后7天内未使用任何会员专属权益（免运费券/专属价/上门取件）可全额退款；已使用权益的按"使用次数×单价"扣除后退还余额。年卡退费按剩余月份比例计算。

## 1.5 会员价与价保
会员专属价商品不参与价格保护（已是会员最优价）；会员价与平台券可叠加，与秒杀价互斥取更优。开通会员前的历史订单不追溯会员价差价。

## 1.6 会员冻结
连续3个月未登录+长期白嫖行为（开通后高频退货）触发会员冻结：冻结期7天，冻结期间不影响已购权益发放但不可新领；连续2次冻结将关闭续费通道12个月。

## 1.7 退款订单与会员权益
退款订单消耗的免运费券当次即恢复至账户（原券未过期则原样恢复，已过期按原有效期+30天补发）；退款订单不退还已享受的会员专属价差价。

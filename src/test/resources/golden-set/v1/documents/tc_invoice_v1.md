# 电商平台发票政策（v1）

## 1.1 发票类型与开具
平台支持开具增值税电子普通发票与增值税电子专用发票。订单确认收货后即可在"我的订单-申请开票"申请，普通发票实时生成，专用发票一般1-3个工作日开具完成。纸质发票仅限企业客户线下申请。

## 1.2 开票时限
订单开具普通发票的时限为确认收货后90天内；超过90天可申请补开，补开时限为下单之日起12个月内。专用发票申请时限为确认收货后30天内，逾期需提供采购方说明函。

## 1.3 开票渠道
开票入口：App/网页端"我的-发票中心"。支持批量勾选多笔订单合并开票，合并开票仅限同一抬头，且订单所属主体相同。开票信息支持保存为常用抬头，下次直接复用。

## 1.4 发票邮寄
电子发票开具后自动推送到账户绑定的手机号与邮箱，可随时在"发票中心"下载PDF重发。企业专票如需纸质版，可选择快递寄送，运费由平台承担，寄送范围覆盖中国大陆地区。

## 1.5 开票金额
开票金额以订单实付金额为准（含运费，不含优惠券抵扣与积分抵扣部分）。使用优惠券、积分抵扣的订单，发票金额按实际支付总额开具；退款订单自动冲减对应发票金额。

## 1.6 开票失败处理
开票失败常见原因：抬头信息不完整、纳税人识别号格式错误、开票名称含特殊字符。失败会在"发票中心"标记原因并支持修改后重新提交，平台每笔订单每30天内允许修改开票信息3次。

## 1.7 平台代开服务费
平台自营商品由平台代开发票，不收取额外费用。第三方卖家商品由其自行开票，开票时间以卖家页面承诺为准，最晚不超过确认收货后30天，超时可发起客服介入。

# 电商平台登录与账号安全政策（v1）

## 1.1 登录方式
支持手机号+验证码、密码、微信/支付宝第三方授权、人脸登录（仅限已实名用户）四种方式。同一手机号仅可注册一个账户，手机号换绑后原账户保留90天可申诉找回。

## 1.2 异地登录
登录行为发生地理或设备变化时，触发短信/人脸二次验证。异地登录状态下敏感操作（支付、改密、换绑）自动进入24小时风控观察期，观察期内大额支付需人工验证。

## 1.3 登录异常判定
异常登录指标：短时间内多地登录、常用设备消失后新设备登录、频繁失败尝试（10分钟内≥5次）。触发后账号临时锁定30分钟，支持"安全认证解锁"提前解锁。

## 1.4 账号冻结
以下情形账号冻结：涉嫌盗号（72小时）、涉嫌刷单/套券（按风控评估，一般7-30天）、监管要求（直至材料齐备）。冻结期间可查看账户但不可交易，冻结原因站内信通知。

## 1.5 盗号处理流程
发现被盗后第一时间：改密+解除陌生设备绑定+在"账号安全-申诉"提交申诉。平台在24小时内冻结原账号交易并启动资金保护（保障盗号期间未授权交易资金，核实后全额返还）。

## 1.6 设备管理
"我的-账号安全-设备管理"可查看全部登录设备（型号/时间/IP），支持远程下线指定设备。同一账号同时在线设备上限5台，超出时最早登录设备自动下线。

## 1.7 登录保护状态
开通过"登录保护"的账号，新设备登录需扫码确认（在其他已信任设备上确认）；信任设备有效期为90天，之后需重新验证。

# 电商平台余额与信用支付政策（v1）

## 1.1 账户余额
账户余额来源：退款到账、提现失败退回、平台补偿、卡券转余额。余额支持支付订单（100%比例）、不支持转账与提现（活动补偿余额可参与提现场景以余额页面为准）。

## 1.2 信用支付（先享后付）
信用支付"先享后付"：符合条件的用户（实名+信用分≥600）可享受"先用后付"，确认收货后次月1日生成账单，还款日为次月10日。逾期按日利率0.05%计息并影响信用分。

## 1.3 钱包安全
钱包支付需验证支付密码（首绑卡开启）；单笔限额：余额支付单笔5万元，信用支付单笔3万元，日累计10万元。大额支付触发短信/人脸二次验证。

## 1.4 余额退还
支付时余额不足可自动组合"余额+其他方式"混合支付，混合支付订单退款时优先退回余额部分至余额账户，其余部分原路退回。

## 1.5 钱包余额利息
钱包余额不计利息，支持"余额生息"可选服务（年化约1.5%）需单独开通，开通后冻结生息，提现/支付自动解冻。

## 1.6 异常账户处理
账户被风控冻结时余额不可用，解冻需通过实人认证+历史交易核验，人工审核1-3个工作日。涉嫌盗刷期间产生的余额变动平台先行赔付，追回后再行扣回。

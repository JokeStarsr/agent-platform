# 电商平台隐私保护政策（v1）

## 1.1 收集信息范围
平台收集的信息包括：注册信息（手机号/姓名/身份证号用于实名）、订单信息（收货地址/商品/金额）、支付信息（支付方式/卡号后四位）、设备信息（型号/系统/IP）、浏览行为（页面/搜索/停留时长）。

## 1.2 信息使用用途
收集信息用于：订单履约、售后处理、风控识别、个性化推荐（可关闭）、营销触达（可退订）。敏感信息（身份证、支付凭证）仅在同条安全链路内处理，不用于分析画像。

## 1.3 信息共享
平台不与第三方共享个人信息，以下情形除外：物流履约（地址/电话给快递员）、支付机构（交易清算）、司法机关/监管（法定要求）、获得用户明示同意的授权场景。共享范围最小化。

## 1.4 信息安全
个人信息加密存储（传输TLS1.2+存储AES256），访问日志脱敏，内部访问最小权限+水印追溯。平台每半年委托第三方做一次安全审计并在官网公布摘要。

## 1.5 自动化决策
个性化推荐与定价均不予公开算法但接受监管；个性化定价仅限符合监管条件的场景（需显著标识"个性化价格"），用户提供《个人信息保护法》第24条要求时提供退出个性化定价入口。

## 1.6 政策更新
隐私政策更新提前30天以站内信+App弹窗公示，重大变更（信息用途/共享范围）需用户重新勾选同意。用户可随时在"设置-隐私政策-历史版本"查阅全部历史版本。

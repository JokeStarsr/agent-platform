# 电商平台分期付款政策（v1）

## 1.1 分期方式
支持信用卡分期与平台合作金融机构消费分期（花呗分期、京东白条等以支持列表为准）。分期期数支持3/6/12/24期，期数以支付页展示为准，部分商品单笔满500元才支持分期。

## 1.2 分期费率
免息期数：3期、6期常作免息促销（以活动页标注为准）；12期费率0.5%-0.8%/月，24期费率0.6%-0.9%/月，具体以银行/机构定价为准。分期手续费在首期一次性收取或按月分摊由放款机构决定。

## 1.3 分期额度
分期消费占用用户信用额度（银行/机构审批），平台不追加额度。额度不足时支付失败，可降低期数、全额支付或更换支付方式，无需人工介入。

## 1.4 分期退款
整单退款时：首期已收手续费的分期账单，手续费按未还期数与手续费比例退还到账；分期形成的授信额度在退款确认后24-48小时内释放。部分退款按比例冲抵未还本金。

## 1.5 分期账单管理
分期订单生成后可在"我的-分期账单"查看每期应还金额与还款日期，支持提前全额还款（机构收取剩余本金0-2%违约金，以机构规则为准）。逾期还款影响征信，请按时还款。

## 1.6 分期风控
同一用户同时进行中的分期订单不超过5笔，或总授信使用率超80%时将提示并可能拦截新分期订单。学生身份用户限制单笔分期金额≤2000元。

# 电商平台配送时效政策（v1）

## 1.1 配送时效总览
现货商品配送时效：一线城市（北上广深杭）1-2天、省会城市2-3天、地级市3-4天、县级市4-6天、乡镇6-8天。以上为承诺区间，超区间72小时可申请时效赔付（见物流异常政策1.6）。

## 1.2 发货时限
现货商品48小时内发货（节假日顺延）；预售商品按页面"预计发货"日期；定制商品按生产周期（页面标注）。20点后付款的订单视同次日零点后处理。

## 1.3 次日达与半日达
次日达覆盖范围：一线城市全部城区+地铁沿线3公里，20:00前付款可次日送达。半日达（上午下单下午到）覆盖北京、上海、广州、深圳、杭州核心商圈，11:00前付款当日送达。

## 1.4 大促时效
618/双11大促期间发货时限宽限为72小时，送达时效整体顺延2-3天，页面在活动期间展示"大促时效"说明。大促订单的时效投诉以活动公告为准，不适用日常时效赔付。

## 1.5 时效计算基准
承诺时效自"付款完成+商家发货"起算，物流揽收后超过12小时无更新的订单自动触发物流核查。偏远地区、跨境、自提订单不适用以上时效标准（见对应政策）。

## 1.6 加急配送
加急配送（2小时达/当日达）覆盖生鲜、药品、3C数码品类，运费15-25元，订单支付后可实时查看骑手位置。加急配送区域内超时30分钟赔偿5元券，超时1小时全额退还加急运费。

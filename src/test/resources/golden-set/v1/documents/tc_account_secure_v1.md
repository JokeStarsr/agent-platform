# 电商平台账号风控与设备安全政策（v1）

## 1.1 风控模型
平台风控覆盖：登录（异常设备/异地）、交易（高频小额试探/异常时间段）、售后（批量退货/高频拒收）、营销（套券/小号）。风控规则按风险等级分为观察、限制、冻结三级措施。

## 1.2 交易风控
单日下单超过20笔或单笔金额超过5万元的账号触发人工复核，复核期间订单正常待支付但暂缓进入商家处理队列。疑似团伙作弊（同IP/同设备多账号联动）按套券条款处理。

## 1.3 售后风控
月退货率超30%或连续2个月退货率超20%的账号，其后续订单进入"售后审核增强"模式：退款需调阅物流回执核实，时间延长1-2个工作日。正常退货权益不受影响。

## 1.4 风控申诉
被限制/冻结的账号可在"安全中心-申诉"提交材料：本人身份证明+交易背景说明。申诉时限：限制类24小时内响应，冻结类3个工作日内响应，材料不齐顺延。

## 1.5 安全锁
支持开启"安全锁"：可锁定支付（需人工扫脸解锁）、或锁定低价商品交易（防未成年人误购）。安全锁开启期间产生的交易，用户可提供未本人操作证明申请全额撤销。

## 1.6 风控协作
配合公安机关的涉诈/涉赌资金协查，平台按法定程序提供数据并先行冻结涉案账号（48小时，可延期）。账户所有人可凭案号向办案机关申请解冻。

# 电商平台偏远地区配送政策（v1）

## 1.1 偏远地区范围
偏远地区指西藏、新疆、青海、甘肃、内蒙古西部、宁夏等配送成本较高区域，具体以结算页运费展示为准。偏远地区订单发货时限为付款后1-3个工作日且送达时限相应延长5-10天。

## 1.2 偏远地区运费
偏远地区订单运费按区域阶梯定价：首重12-20元，续重2-4元/公斤，以结算页为准。单笔订单满199元，首重运费减免10元；满399元免首重运费。

## 1.3 偏远地区时效承诺
偏远地区不承诺具体送达日期，仅提供预计区间（如"预计10-15天送达"）。超区间未送达订单可申请运费补偿券5元/单；签收后该券自动失效。

## 1.4 偏远地区售后
偏远地区退货支持平台合作快递上门取件（县域及以下视快递网络覆盖情况，支持送达驿站自寄）。商家责任售后的往返运费由商家承担，用户责任售后按原下单运费标准承担。

## 1.5 偏远地区鲜活商品
鲜花、生鲜等时效敏感商品的偏远地区配送范围受限，页面未标注"偏远可发"即默认不支持偏远配送。已付款但地址为不可配送区域时，平台在24小时内通知并全额退款。

## 1.6 偏远地区签收
偏远地区包裹默认投递至乡镇级快递点，快递员送达后短信通知，用户务必及时取件：生鲜类商品超过12小时未取件变质由用户自行承担，普通商品超3天未取件退回发件地的运费从退款中扣除。

# 电商平台跨境电商配送政策（v1）

## 1.1 保税仓业务
跨境电商保税仓模式：商品提前备货至国内保税仓，用户下单后从保税仓报关发货，时效3-7天。购买需实名认证（身份证号）并与支付人一致，一份身份证对应单笔订单。

## 1.2 跨境直邮
直邮模式商品从境外仓库发货：美国仓7-12天、日本仓5-9天、欧洲仓10-15天送达，海关清关时间2-5天。直邮商品物流跟踪支持英文/中文双语节点提示。

## 1.3 跨境税费
跨境商品按综合税率计征（行邮税/跨境电商综合税），税款在下单时预收代缴，实缴与预缴差异多退少补。单次交易限值5000元/年度26000元（个人），超出无法清关。

## 1.4 跨境退货
保税仓商品支持7天无理由退货（退回保税仓），退货运费30元/单由用户承担（运费险跨境版可覆盖）；直邮商品仅支持质量问题退货，运费由商家承担。跨境商品退货周期一般15-30天。

## 1.5 清关异常
清关失败常见原因：身份证信息不符、超限值、禁限物品。清关失败后订单取消并全额退款（含税费）。身份证有效期临近（<3个月）可能被海关拦截，下单前请确认。

## 1.6 跨境售后
跨境商品质量问题检测周期15天，质量确认后按退全款或补发处理。化妆品、保健品等品类不支持退换（已拆封），页面标注"不支持退换"的商品下单前请确认。

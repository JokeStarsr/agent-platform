# 电商平台价格保护政策（v1）

## 1.1 价保适用范围
平台自营商品默认享受价保：购买后15天内（自签收日起算），同商品出现降价，可申请差价退回。第三方卖家的价保承诺以商品页标注为准（有"价保XX天"标识才有）。

## 1.2 价保计算口径
比价基准为同商品同 SKU（规格/颜色/套餐完全一致）在平台的直降价格，不含使用优惠券、会员折扣、积分抵扣后的到手价。若降价系使用更大面额券造成，不属于价保范围。

## 1.3 申请流程
申请入口："我的订单-申请价保"。系统自动检测同 SKU 历史价格，3秒内返回结果；差价以无门槛优惠券形式发放至账户，有效期60天，支持多笔订单分别申请。

## 1.4 价保金发放
价保金以'价保券'形式注入账户，可全场无门槛使用，不设找零、不提现、不转赠。价保券使用不影响订单后续退款金额计算（退款按实付口径）。

## 1.5 大促价保
618/双11期间，价保窗口延长为活动结束后30天。预售订单价保自尾款支付日起算，与预售价保条款（见预售政策1.5）以更优者为准，不重复享受。

## 1.6 价保除外
以下情形不参与价保：限时秒杀/清仓/临期特卖商品、企业采购订单、礼品卡结算订单、已申请过价保的同品订单。价格调整已通过平台公告或站内信公示的不适用价保（公示时间≥24小时）。

# 电商平台发票红冲政策（v1）

## 1.1 红冲触发条件
以下情形可申请发票红冲：发票抬头或税号错误、开票金额与实际支付不符、订单发生退款退货、重复开票。红冲入口："我的-发票中心-红冲申请"。

## 1.2 红冲时限
普通发票红冲时限为开票后180天内；专票红冲需在下月申报期内完成，跨月红冲需税务系统条件校验，耗时可能延长至5个工作日。超过时限的红冲需人工客服审核。

## 1.3 红冲后重新开票
红冲成功后原发票作废，可立即发起重新开票。重新开票的金额不得超过红冲金额，抬头可任意变更，不重复收费。

## 1.4 已抵扣专票处理
企业方已认证抵扣的专票无法直接红冲，需由采购方先开具"红字信息表"（各省电子税务局申请），平台凭红字信息表在2个工作日内完成红冲并重新开具。

## 1.5 红冲状态查询
红冲申请支持在"发票中心"查看实时状态：待审核/红冲中/已红冲/已驳回。驳回时注明原因（如超出时限、信息不符），支持修改后重新提交，每笔发票红冲申请不超过3次。

## 1.6 红冲与退款的关系
订单退款后的发票处理：全额退款自动红冲全部发票；部分退款按退款比例红冲对应金额，剩余金额保留原发票。退款到账后系统在24小时内自动发起红冲，无需用户操作。

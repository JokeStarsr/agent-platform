# 电商平台评价与晒单政策（v1）

## 1.1 评价时间
确认收货后可评价，好评/中评/差评三档+文字内容+图片（可选）。默认评价期为收货后30天，超过未评价自动好评（系统标注"默认好评"字样不计入好评率）。

## 1.2 退款订单评价
全额退款订单关闭评价入口，该订单计入商家好评率分母（按未评价计不扣分）。部分退款订单可正常评价，评价内容需客观反映商品（退款不影响评价尺度）。

## 1.3 评价修改
评价发布后支持1次修改（仅可限时改评，评价后30天内）；差评修改后商家回复保留。评价删除：仅违规评价（辱骂/广告/无关内容）被平台删除并在评价区标注"违反平台规范已删除"。

## 1.4 评价打标
"好评返现"诱导评价属违规：商家被查实后店铺评分扣分并限制活动报名30天。平台对"刷单评价""机器评价"定期清洗，清洗后好评率按真实评价重算。

## 1.5 差评处理
差评触发商家商家回复按钮（24小时内可回复一次），回复内容审核后展示。用户可在差评后补充追评（商家不可删除，仅可申诉至平台核验消费者身份）。

## 1.6 晒单返积分
图文晒单奖励：晒单积分20分/单（每月上限200），晒单内容要求真实主图+至少20字评价，虚假晒单（盗图/刷单）追回积分并限制晒单资格30天。

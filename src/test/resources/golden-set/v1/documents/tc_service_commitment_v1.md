# 电商平台服务承诺与赔付政策（v1）

## 1.1 极速退款承诺
符合极速退款条件（见退款时效政策1.3）的订单，退款自申请受理起2小时内到账，超时赔付5元券（每月限赔2次）。

## 1.2 发货时效承诺
现货24小时内发货（不含预售/定制），超时发货按5元/单赔付违约金（自动发放至账户，无需申请），同时用户可无责取消订单全额退款（已发货的除外）。

## 1.3 正品保障
平台自营商品承诺正品保障：假一赔十（以实际支付金额为基数赔付）。第三方商品假一赔三+500元保底（见投诉政策1.5）。赔付须经品牌官方/第三方质检机构认定。

## 1.4 价格保障
价保承诺见价格保护政策，大促期间自动延长价保窗口。承诺范围内未自动价保的订单，人工核查后48小时内补发差价券。

## 1.5 服务标准
服务标准：在线客服5分钟响应、电话3分钟接通、纠纷72小时仲裁、投诉24小时首响。超时不响应每次赔付5元券（月上限10次），自动计入下次售后处理优先级。

## 1.6 安全承诺
平台对盗刷/盗号造成的用户资金损失先行兜底（见登录政策1.5），核实后7个工作日内全额返还。平台系统故障（非用户责任）导致的重复扣款/错误扣款，24小时内自动原路退回。

## 1.7 承诺免责情形
以下情形不适用服务承诺赔付：不可抗力（见不可抗力政策）、用户提供信息错误、用户未配合提供必要凭证、恶意套取赔付的行为。

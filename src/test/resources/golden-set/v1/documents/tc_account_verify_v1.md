# 电商平台实名认证政策（v1）

## 1.1 认证要求
实名认证要求：姓名+身份证号+人脸识别（或银行卡要素校验）。未实名用户可浏览与加购，但不可支付下单。跨境、二手、虚拟商品强制实名。

## 1.2 认证信息修改
姓名与身份证号经实名后不可修改（与公安部数据核验一致）；仅支持因姓名变更（提供户口本/公安变更证明）申请人工修改，审核3-5个工作日。已实名认证的账户支持每年1次手机号变更。

## 1.3 认证明细
一个身份证号可绑定最多3个平台账户；绑定超过限额需先注销其他账户。未成年人实名须监护人授权（见未成年人保护政策）。

## 1.4 认证失败处理
人脸识别失败常见原因：光线不足、美颜滤镜、证件照与本人差异大。每日认证尝试上限5次，超限次日恢复；连续3天失败需转人工视频核验（工作时间30分钟内接入）。

## 1.5 认证数据使用
实名信息仅用于：实名交易、风控识别、税务机关要求、海关清关（跨境）。信息加密存储，除上述用途外不用于任何营销，不对外提供（法定机关要求除外）。

## 1.6 认证过期与失效
实名信息随身份证有效期同步（临期3个月提醒更新）；国籍变更、身份信息变更后原实名自动失效，需重新认证，账户内余额冻结至重新认证完成。

# 电商平台拆单与合单政策（v1）

## 1.1 自动拆单
一单多商品由不同仓库出库的订单自动拆分为多个包裹独立发货，物流单号分别推送，退款按包裹分别处理，不影响其他包裹的物流。

## 1.2 预售拆单
含预售商品与现货商品的订单自动拆分：现货部分立即发货，预售部分按"预计发货日"发货。拆分后运费分摊到各包裹（首重分档），拆单不另收操作费。

## 1.3 合单规则
同店铺、同仓库、可同时履约的商品自动合单为一个包裹发货；用户无需操作。合单订单的优惠分摊按商品金额比例计算，退款按比例退回（见优惠叠加政策1.6）。

## 1.4 人工合并包裹
同一用户短时间内的多笔同店铺订单支持"合并包裹"（限未发货订单，按地址一致性校验）：合并后共享一个物流单号，节省运费。合并时优惠券退货规则不变。

## 1.5 拆单售后期
拆单后的各包裹独立计算收货时间与售后期；用户可分别对每个包裹发起售后。合单订单用户申请售后的范围超出一个包裹时，需分别提交申请（每包裹一单）。

## 1.6 拆单地址
拆单包裹默认发往同一收货地址；特殊需求（分批寄往不同地址）需在下单前分单提交，已拆单订单不支持二次分址。

# 电商平台订单修改政策（v1）

## 1.1 修改收货地址
待发货订单支持免费改址；已发货订单改址视物流情况（未出库可拦截改址，已出库需联系快递改投，可能产生10-20元改投费自付）。每个订单支持改址2次。

## 1.2 取消订单
订单取消规则：待付款关闭（见下单流程）、已付款未发货2小时内可免审取消，超时提交的取消申请商家需在24小时内处理；已发货订单取消需走退货流程。

## 1.3 修改商品
已提交订单不支持直接修改商品数量/规格，需取消后重新下单。取消成功且优惠券未被占用的，原券自动退回（见优惠券政策1.4）。

## 1.4 合并与拆分
多店铺商品分开下单独立物流；同店铺多商品可合并为一单。已下单订单不支持合并；拆单由系统按仓库/预售自动处理（见拆单政策）。

## 1.5 修改发票信息
订单已开票的发票信息修改走红冲流程（发票政策）；未开票订单的抬头可在支付后修改（发票抬头政策）。

## 1.6 订单备注
"买家备注"（如配送时段、开箱要求）在提交订单时填写，商家按备注执行；备注不构成服务承诺变更，特殊需求（代开发票、赠品索要）不受备注约束。

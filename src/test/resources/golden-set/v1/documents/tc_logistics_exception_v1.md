# 电商平台物流异常处理政策（v1）

## 1.1 丢件处理
快递丢件认定：物流信息超过7天无更新且快递公司确认为遗失，或签收前快递公司通知包裹丢失。丢件订单全额退款或免费补发（用户二选一），赔付款含运费。

## 1.2 破损处理
外包装破损可拒收；签收后发现商品破损，48小时内凭外包装照片+商品照片申请售后，商家核实后按补发/退款处理。快递面单与内物相符性以开箱视频为准。

## 1.3 错投/误签
包裹被投递至错误地址或他人代签：发现后联系快递员拦回，或在订单详情发起"物流异常申诉"，平台在24小时内协调快递改投。因错投导致商品丢失的，按丢件流程处理。

## 1.4 物流拦截
发货后未签收的包裹支持拦截（部分快递不支持，以系统提示为准）。拦截成功后退款原路返回到账，拦截费5元/单从退款中扣除；拦截失败需拒收或退货处理。

## 1.5 滞留件
包裹到达驿站/自提点超7天未领取，快递退回发件地，退件产生的退件运费（首重10元）从退款中扣除。生鲜等易腐商品滞留超时变质由用户自行承担。

## 1.6 物流时效赔付
超时赔付：承诺时效（结算页预计天数）超过72小时未送达且非用户原因，赔付5元无门槛券；超过7天未更新物流节点，按丢件流程转入核查并在48小时内给出处理结论。

# 电商平台特殊品类退换政策（v1）

## 1.1 生鲜食品
生鲜、冷冻、短保食品（保质期≤30天）不支持7天无理由退货，仅支持质量问题售后：签收后24小时内提交坏果/变质凭证（照片+快递面单）可退全款，无需寄回。缺斤少两按缺失比例退款。

## 1.2 定制商品
定制（刻字、照片印刷、服装定制）商品不支持无理由退换，仅支持质量问题退换。商家开始生产后不可取消订单，生产前取消需承担材料费（订单金额的20%）。

## 1.3 贴身衣物与开袋商品
内衣裤、泳装、袜类等贴身商品一经拆封不支持退换（吊牌完整的可退）。美妆个护类开封使用后非质量问题不影响二次销售前提下仍可退，但需原包装完整。

## 1.4 贵金属与珠宝
金银饰品、钻石、玉石支持7天无理由退货，签收时需当着快递员面验货并保存证书吊牌；拆袋后证书遗失的按质量问题处理流程需提供回购凭证。

## 1.5 大件家具家电
大件商品（家具、大型家电）支持7天无理由退货，退货运费由消费者承担（平台代收标准价），拒收产生的邮费同样由消费者承担。安装拆封后无理由退货可能产生翻新费（货款的10%-20%）。

## 1.6 虚拟与数字商品
话费充值、会员服务、数字课程等虚拟商品一经发货即时生效，不适用无理由退货；因平台原因未到账的48小时内原路全额退款。预售期未生效的虚拟商品可申请取消。

# 电商平台自提与代收政策（v1）

## 1.1 配送方式
订单配送支持送货上门、驿站代收、快递柜投递与门店自提四种方式，可在"我的-收货地址"为每个地址设置默认配送偏好，也可在结算页单笔调整。

## 1.2 驿站与快递柜
驿站/快递柜投递的包裹在入柜后推送取件码短信，出库前支持改址；驿站包裹存放7天，快递柜存放24小时（超时收取0.5元/天超时费，部分柜机可申请免费延长48小时一次）。

## 1.3 门店自提
自营门店支持线上下单门店自提：订单支付完成后2小时可提，自提保留期7天，超期仍未提取订单自动取消并全额退款。自提时需出示取件码+身份证明（可代办代取）。

## 1.4 代收规范
快递员默认将包裹放置前台/物业委托代收需推送"签收提醒"（含放置位置照片）。用户设置过"不可代收"的地址，快递员不得代签，违规则按丢件担责。

## 1.5 自提点覆盖
自提点覆盖范围：城市核心区域3公里内必有驿站或自提点，县城5公里内，乡镇以快递网点为准。自提点营业时间一般为8:00-22:00，大促期间延长至23:00。

## 1.6 自提售后
自提/代收包裹的售后期从实际取件时间起算；代收包裹从签收提醒推送时起算（用户24小时内可申请更正签收时间）。驿站提取后发现的少件问题按开箱视频凭证处理。

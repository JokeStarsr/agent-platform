# 电商平台验货质检政策（v1）

## 1.1 签收验货
建议签收前检查外包装是否完好；大件商品支持先验后签。外包装有明显破损、挤压变形时，可拒收或开箱验货后确认。签收后发现商品破损，请在48小时内提交照片凭证申请售后。

## 1.2 质量问题认定标准
质量问题包括：功能故障、外观明显瑕疵（划痕/变形/色差超出可接受范围）、异味影响使用、缺件（配件/说明书/吊牌）。轻微色差、尺寸误差±2cm以内不属于质量问题。

## 1.3 质检流程
质量问题售后申请后，商家可选择：直接退款（小件）、寄回检测（大件）、上门检测。寄回检测周期：收货后3-5个工作日出具检测报告，检测结果支持在线查看，非质量问题退回运费需自理。

## 1.4 第三方质检
对商家检测结论存疑时，可申请平台第三方质检（中检/华测等合作机构），费用160元/次，检验结果非质量问题由用户承担费用，质量问题由商家承担并全额退还。

## 1.5 电子质保凭证
电子质保卡随购买记录自动生成，质保期自签收次日起算，可在"我的-质保卡"查询剩余期限、维修记录、换新次数。电子质保卡与纸质保修卡具有同等效力。

## 1.6 翻新与二手
翻新机、官方认证二手商品明确标注"翻新/二手"字样，支持7天无理由退货（包装含全新配件）。翻新商品质保期一般为3-6个月（以页面标注为准），不享受延保。

# 电商平台下单流程政策（v1）

## 1.1 下单流程
下单路径：选品加入购物车 → 结算（地址/优惠/支付方式）→ 提交订单 → 支付 → 商家备货发货。订单提交后30分钟内未支付自动关闭，关闭后可在"待付款"重新发起（同一商品库存变化时以重新支付页为准）。

## 1.2 订单状态说明
订单状态流转：待付款 → 待发货 → 待收货 → 已完成；另有已取消、已关闭、退款中（售后）。订单列表支持按状态筛选，已完成订单享售后期（7天无理由/15天换货/质保承诺以商品页为准）。

## 1.3 订单锁定与优惠
订单提交时锁定当时价格与可用优惠30分钟（支付时限内），超时重新提交时价格以最新为准。锁价期间的优惠券不可重复使用；订单关闭后已用券退回（见优惠券政策1.4）。

## 1.4 订单确认
订单提交后系统自动确认，无需人工。确认后2小时内可免审取消（见订单修改政策）；超时取消需商家审核。提交订单即视为同意《平台交易规则》与对应商品服务协议。

## 1.5 异常订单
系统风控标记的异常订单（同地址高频、金额异常、疑似刷单）可能被拦截支付或提交后置审核，置审核订单48小时内给出结论，结论前订单保持"待审核"不发货。

## 1.6 订单记录
全部订单保留在"我的订单"，支持按日期/店铺/商品名检索，订单详情含物流单号、发票开票入口、售后入口。已完成的订单数据保留5年（税务要求），导出见个人信息导出条款。

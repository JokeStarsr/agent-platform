# 电商平台大促活动总则（v1）

## 1.1 活动定义
平台大促活动包括：品牌日（每月2场）、会员日（每月8日）、618年中大促（6月16-18日）、双11（11月10-11日）、年终盛典（12月20-31日）。活动规则以当期活动页面公示为准。

## 1.2 大促价格规则
大促价 = 活动价（商家报名锁定，活动期间不可改动）。大促商品价格在活动开始前72小时锁定，锁定后不支持商家修改；平台提供"已购保价"服务（价保窗口详见价保政策1.5）。

## 1.3 大促库存
大促库存 = 活动库存（报名时锁定）+ 日常库存。活动库存售罄显示"已售罄"，可进行"到货提醒"。预售订单的库存按订金支付数扣减，尾款率不足的按实际成交结算。

## 1.4 大促优惠叠加
大促叠加层级遵循优惠叠加政策总则，另享：平台官方满减券（可与店铺券叠，不可与无门槛券叠）、大促红包（全场通用，不可与品类券同用）。叠加后实付不得低于0元。

## 1.5 大促服务保障
大促期间服务承诺整体顺延：发货时限72小时、客服响应10分钟、人工优先队列。大促订单的退款优先极速通道（V2以上自动触发），售后时效不计入日常承诺（以活动公告为准）。

## 1.6 大促风控
大促期间风控升级：优惠券风险订单（异常小号/异常设备）直接取消不通知（保留申诉入口），商家违规刷单降权15天。大促产生的纠纷优先按活动规则条款裁决，规则未明确处回退日常政策。

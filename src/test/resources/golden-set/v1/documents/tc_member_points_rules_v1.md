# 电商平台会员积分细则（v1）

## 1.1 积分获取
积分来源：订单消费（实付金额1元=1积分，会员倍率见等级权益）、评价晒单（图文晒单20积分/单，每月上限200）、签到（连续签到7天得50积分）、活动任务（以每期活动规则为准）。

## 1.2 积分抵扣
积分抵扣比例：100积分=1元，单笔订单积分抵扣上限为订单金额的30%（V4会员50%）。积分抵扣金额计入退款分摊（见优惠叠加政策1.6），退款退回的积分按原有效期续期30天。

## 1.3 积分有效期与过期
积分有效期12个月（获取当月起算），到期自动清零。积分变动可在"我的-积分明细"查看来源与到期批次，支持按到期时间排序，临期积分优先使用。

## 1.4 积分商城
积分兑换：实物商品（纯积分兑换/积分+现金）、优惠券（500积分=5元券等）、数字权益。兑换订单7天内质量问题支持退换，退换退回积分。虚拟兑换一经发放不支持退款。

## 1.5 积分异常处理
风控判定异常获取的积分（刷单、违规评价）将被冻结或回收，回收以站内信+短信通知，用户可在7天内申诉。正常消费积分不受影响。

## 1.6 积分转让
积分不支持转让、转赠、提现，注销账户积分清零（见退会注销条款）。企业采购订单不产生个人积分，需开具"企业积分发票"的可联系大客户经理。

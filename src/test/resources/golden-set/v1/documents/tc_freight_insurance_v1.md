# 电商平台运费险政策（v1）

## 1.1 运费险说明
运费险是购物时可选的退货运费保障：购买运费险后，退货产生的首重运费（默认12元，以保单为准）由保险公司赔付。保费2-5元，以支付页展示为准。

## 1.2 赔付规则
退货退款成功且商家确认收到退货后，运费险自动理赔，赔付款一般在24小时内到账至支付账户余额。赔付金额按运费险承保标准（首公斤内12元或15元），超重部分自付。

## 1.3 免运费险场景
平台对以下场景赠送运费险：会员V2及以上、签收后7天内退货、首次退货订单。赠送运费险的订单退货时不扣减任何运费，用户无需再购买。

## 1.4 不赔付情形
以下情形运费险不赔付：无理由拒收（未实际收到商品）、换货（仅退货运费险）、商家责任退货运费（由商家承担）、超过保单约定的退货次数后再次使用。

## 1.5 多次退货限制
同一用户同一保单周期内（90天）累计退货理赔满5次后，后续订单无法购买运费险；连续3次退货理赔率100%的用户，运费险购买价格上浮（按平台风控模型评估）。

## 1.6 理赔争议
对理赔金额或拒赔结论有异议时，可在理赔详情页发起申诉，保险公司3个工作日内复核；复核结果仍不满意可向平台客服申请人工介入，平台与保险方联合处理。

# 电商平台投诉与纠纷处理政策（v1）

## 1.1 投诉受理范围
受理范围：商品质量纠纷、服务态度投诉、商家违规（虚假宣传/售假/私自改价）、快递问题、平台规则争议。不受理：已进入司法程序的事项、其他平台争议、超时效（180天）投诉。

## 1.2 投诉升级路径
投诉处理三级：一级（商家直接协商，24小时内响应）→ 二级（平台介入，72小时内仲裁）→ 三级（纠纷委员会听证，每周四）。每级结案后用户不满意可于7日内发起升级。

## 1.3 平台介入条件
满足任一条可申请平台介入：商家超48小时未响应、协商失败2次以上、涉及人身安全/资金安全、商家注销/失联。介入后平台冻结争议订单款项，仲裁前不向商家结算。

## 1.4 仲裁规则
仲裁依据：订单快照、物流记录、聊天记录、用户提交凭证。举证责任：商品质量由商家自证（进货凭证/质检报告），服务问题由平台核查录音记录。仲裁结论7日内以站内信+短信送达。

## 1.5 售假处理
售假认定后：全额退款+三倍赔偿（不足500元按500元）+商家保证金扣罚+商品下架。用户需提供品牌鉴定或平台抽检结论。涉嫌售假金额超过5万元的移交市场监管部门。

## 1.6 恶意投诉
滥用投诉权利（高频无理投诉、索要赔偿至威胁）将降级用户投诉权重并限制平台介入次数；情节严重（敲诈商家）封禁账号并保留追诉权利。

## 1.7 投诉保密
投诉方信息全程保密，商家仅可见脱敏信息（用户ID后4位）；投诉材料不经用户同意不对外提供（法定机关除外）。报复性骚扰用户将被商家保证金直接赔付。

# 电商平台换货维修服务政策（v1）

## 1.1 换货服务
质量问题换货：签收15天内，商品存在性能故障可申请换新，商家承担往返运费，换货时效为收到退货后48小时内发出新品（现货），缺货时告知等待周期或提供替代品选择。

## 1.2 维修服务
家用电器与小家电支持1年质保维修（以商品页质保说明为准），质保期内的性能故障由商家/厂商承担维修费与往返运费。维修周期一般7-15个工作日，超期可申请换新或退款。

## 1.3 以旧换新
平台支持特定品类（手机、家电、服饰旧衣）以旧换新：旧品估价 → 抵扣新商品金额 → 新机发货 → 旧品上门回收（服务范围以页面为准）。旧品估价锁定3天，超期需重新评估。

## 1.4 延保服务
付费延保（+1年/+2年）保障范围与整机一致，购买后30天内可无理由退订；延保期内商品停产缺件时，按折旧价90%赔付现金券或直接换等价替代机型。

## 1.5 上门服务
大件商品支持上门取件维修与上门安装。上门安装预约后48小时内响应，安装师傅需出示平台工牌，未出示工牌可拒绝开门安装并在平台投诉。

## 1.6 服务工单
所有换货/维修/以旧换新均生成服务工单，工单详情记录进度节点（受理/收件/检测/换发/完成），支持在"我的售后-服务工单"实时跟踪，工单超48小时无进展可一键催促。

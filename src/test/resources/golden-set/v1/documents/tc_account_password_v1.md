# 电商平台密码管理政策（v1）

## 1.1 密码规则
登录密码要求：8-20位，至少包含字母+数字（建议含特殊字符）。支付密码要求：6位数字，与登录密码不同。密码错误连续5次触发锁定，10分钟冷静期或安全认证解锁。

## 1.2 找回密码
找回流程："登录页-忘记密码"→ 手机验证码/实名认证任一途径 → 设置新密码。绑定邮箱也可作为找回通道（需邮箱链接24小时有效）。找回成功后通知全部登录设备下线。

## 1.3 修改密码
修改登录密码需当前密码或短信验证；修改支付密码需当前支付密码+实名信息。常规修改密码后，其他设备自动下线；近30天改密≥3次将限制1个月内不可再改。

## 1.4 弱密码检测
使用常见弱密码（123456、手机号、生日组合）的账号，每季度提醒一次并建议更换；连续2个季度未更换的账号限制营销推送。

## 1.5 密码安全承诺
平台不存储明文密码（加盐哈希存储，一用户一盐），不通过任何人工渠道索要密码。用户因泄露密码给他人造成的损失，平台核实后按盗号资金保护条款协助追回。

# 电商平台客服渠道与服务时间政策（v1）

## 1.1 客服渠道
客服渠道：App/网页在线客服（即时聊天）、电话客服（400-800-1688）、工单邮件（service@example.com）、站内信留言。各渠道服务记录互通，切换渠道无需重复描述问题。

## 1.2 服务时间
在线客服与电话客服：每日8:00-23:00（法定节假日缩短为10:00-20:00），大促（618/双11）期间7×16小时（8:00-次日0:00）。凌晨留言工单次日10:00前响应。

## 1.3 响应时效
在线客服排队等待不超过5分钟；电话客服接通等待不超过3分钟；站内信工单4小时内首次响应。AI智能客服7×24小时可用，复杂问题自动转人工（见转人工说明）。

## 1.4 转人工机制
智能客服在以下情形自动转人工：用户明确要求人工、敏感/有害内容、置信度低于阈值、连续2次未能解决问题、涉及退款争议升级。转人工工单生成后在30秒内分派至空闲坐席。

## 1.5 会话保留
会话记录保留180天（用户侧可见，"我的-客服-历史会话"），涉及纠纷的会话延长保留2年。聊天窗口支持上传图片/视频凭证，单个文件不超过20MB。

## 1.6 客服权限
客服无权处理：支付密码重置、账户资金划转、未授权数据导出；涉及资金安全的操作一律跳转自助流程或转专项坐席（需双重身份核验）。任何情况下客服不会索要支付密码与短信验证码。

# 电商平台签收规范政策（v1）

## 1.1 本人签收
包裹建议本人当面签收并核对商品数量与外观。快递员交付时，用户可要求先验货后签收，快递员不得拒绝；强制要求"先签收后验货"的可拒收并投诉。

## 1.2 委托代签
委托他人/物业/柜机代签的，代签视为本人签收，签收后商品保管责任转移。贵重商品（订单金额≥5000元）默认不可代签，需本人验证身份签收。

## 1.3 外观破损处理
外包装破损时当场拒收或拍照留证后签收；签收后发现内物破损，48小时内提交外包装+内物照片可认定快递责任（见物流异常政策1.2）。

## 1.4 少件与错发
签收核对发现少件：先与快递员当面核对面单重量记录；确认少件后在24小时内提交开箱视频，平台核实后按补发处理。错发商品按"七天无理由退货"或商家召回处理。

## 1.5 拒收规则
支持无理由拒收（未拆封、未影响二次销售），拒收后退款原路返还，运费扣除规则：包邮订单拒收扣除发出运费10元（用户原因）或按商家承诺承担。拒收后退款时效2-5个工作日。

## 1.6 签收状态变更
系统延迟推送签收状态时，可在订单详情点击"物流有疑问"更正签收时间，更正后售后期按实际签收时间重新计算；同一订单仅可更正1次。

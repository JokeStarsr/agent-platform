# 电商平台未成年人保护政策（v1）

## 1.1 未成年人账户
未满18周岁用户注册需监护人同意（注册流程中监护人验证：验证监护人手机号+关系说明）。未满16周岁不得单独注册支付账户，须由监护人开设并由监护人管理。

## 1.2 未成年人消费限制
已认证未成年人账号：单笔订单≤500元，单月累计≤2000元。游戏、直播打赏类虚拟物品对未满18周岁一律禁售。未成年人误购大额商品的，监护人可凭监护关系证明申请全额退款（核实后24小时内处理）。

## 1.3 未成年人模式
"青少年模式"可在设置为孩子账号开启：开启后仅展示经过筛选的商品目录，禁用优惠券/积分营销推送，订单需监护人二次确认（短信/人脸）。模式每6个月需监护人重新确认。

## 1.4 未成年人信息保护
未成年人个人信息单独加密存储，不参与个性化推荐与商业画像，不以任何形式向第三方披露（监护人查询除外）。未成年人账号的浏览与消费痕迹保留30天后清理。

## 1.5 未成年人误购退款
监护人发现未成年人未经授权消费，可提交退款申请（需提供：户口本/出生证明/亲子关系公证+消费场景说明），平台核实后在7个工作日内全额退回原支付账户，且该笔消费不计入未成年人消费限额。

## 1.6 举报通道
发现向未成年人销售违规商品（烟酒、管制物品、诱导充值内容）可通过"客服中心-未成年人保护"举报，平台48小时内下架排查并反馈结果，涉刑案件移交公安机关。

# 电商平台赠品政策（v1）

## 1.1 赠品说明
满赠、买赠活动赠送的赠品与主商品同步发货。赠品为独立SKU，计入订单记录，支持单独查看；赠品数量有限，赠完即止（页面标注"赠完为止"的活动不补赠）。

## 1.2 赠品退换
主商品退货时，未开封赠品需随货一并退回；赠品缺失或已使用，按赠品价值（页面标注价值）从退款中扣除。主商品换货时赠品无需退回，赠品质量问题支持单独换发。

## 1.3 赠品质量保障
赠品享受质量保障：7天内出现影响使用的性能问题，支持补发或按赠品标价退款。赠品不参与价保、不参与以旧换新、不单独开具发票（随主商品发票备注）。

## 1.4 拒收与丢件
赠品与主商品分开包裹发货时，赠品单独丢件按赠品价值赔付；主商品已签收、赠品长时间未到，可在订单详情申请补发，平台核实后3日内安排补发。

## 1.5 小样试用装
购买正装附赠的小样试用装属赠品范畴，拆封使用后不单独退换。试用小样在页面标注"试用品"的，仅随正装订单发放，不单独售卖、不补发。

## 1.6 积分赠品与周边
积分商城兑换的实物赠品（马克杯、帆布袋等）7天内质量问题支持换发，不支持无理由退货；节日限定周边赠品限量发售，售罄不补。

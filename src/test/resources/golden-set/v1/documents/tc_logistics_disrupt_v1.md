# 电商平台不可抗力配送政策（v1）

## 1.1 不可抗力范围
不可抗力包括：自然灾害（暴雨/台风/地震/洪水）、政府管制（封控/交通管制）、快递停运（全网性）、网络攻击、公共卫生事件。平台在事件发生48小时内发布受影响区域与恢复时间预估公告。

## 1.2 顺延规则
不可抗力期间的订单发货与送达时限自动顺延（顺延天数=事件持续天数+1天），顺延期间不适用时效赔付（见物流异常政策1.6）。公告恢复后24小时内恢复发货通道。

## 1.3 受影响订单处理
用户可对受影响订单选择：继续等待（自动顺延）、取消订单（全额退款）、保留订单改址（重新计算时效）。生鲜等易腐品受影响无法收货时，用户可选择退款或改约送达窗口。

## 1.4 低温与高温预警
冬季北方部分地区（-15℃以下）与夏季高温（38℃以上）期间，生鲜、药品等温控商品配送范围收窄，平台提前24小时推送区域调整通知。

## 1.5 保障措施
不可抗力期间的库存商品优先保障医院/社区保供订单（页面标注"保供优先"）。快递恢复后平台安排优先补发受影响订单，补发无需重新下单。

## 1.6 证明与争议
以气象台预警/政府部门公告/快递官方公告作为不可抗力认定依据。用户对认定有异议的，可提供当地证明材料申请人工复核，3个工作日内答复。

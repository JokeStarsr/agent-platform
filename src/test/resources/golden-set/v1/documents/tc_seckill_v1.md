# 电商平台秒杀活动政策（v1）

## 1.1 秒杀模式
秒杀商品在固定场次（每日10点/20点）限量开抢，售完即止。商品以秒杀价售卖，秒杀价即为活动价，不与其他优惠叠加（会员折扣除外）。

## 1.2 秒杀资格
秒杀场次需实名认证用户方可参与；同一账号同一场次限购1-5件（以页面标注为准）。未实名、新注册不足24小时、历史恶意退款超过3次的账号将被限制参与。

## 1.3 秒杀订单支付
秒杀订单生成后需在15分钟内完成支付，超时订单自动取消。秒杀商品支持正常退换货，但退货后不再保留秒杀价重复购买资格（按页面库存重新抢购）。

## 1.4 秒杀售后
秒杀商品享受与普通商品一致的售后权益（7天无理由、质量问题等）。秒杀价商品的发票按实付秒杀价开具。秒杀商品缺货时平台全额退款并补偿5元无门槛券。

## 1.5 防作弊规则
使用外挂软件、多账号抢购、频繁取消订单占用库存等行为将触发风控，平台有权取消相关订单并限制账号参与场次资格。判定依据包括设备指纹、IP聚合、支付账户关联。

## 1.6 秒杀与价保
秒杀商品不参与价格保护（已是最低价）。秒杀结束后商品恢复原价，可参与常规优惠。秒杀预告场次的商品在开抢前1小时不可加购，避免库存占位。

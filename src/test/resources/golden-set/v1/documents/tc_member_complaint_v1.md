# 电商平台会员申诉与权益找回政策（v1）

## 1.1 申诉入口
会员对等级判定、权益冻结、积分回收、营销权限有异议时，可在"我的-权益-申诉中心"提交申诉，需附等级变动/积分变动截图等凭证，平台3个工作日内复核并短信通知结论。

## 1.2 等级误判申诉
等级按月度消费额自动判定（见等级体系条款），对统计口径有异议（如退款消费是否计入）可在次月1日-15日提出申诉，复核将按"实际有效消费额=实付-退款"重新计算，复议结论不再二次申诉。

## 1.3 权益找回
以下情形可一次性找回权益：系统原因导致免运费券未发放/逾期作废、会员积分被误回收、会员日折扣未生效。找回需提供订单号与时间，补发的券/积分按原有效期重新计算。

## 1.4 冻结申诉
因违规退款/恶意差评被冻结权益的（权益冻结条款），可在冻结期内提供申诉材料（订单沟通记录、签收凭证）申请复核，复核通过立即解冻，冻结时长不补。

## 1.5 注销后悔
账户注销90天内（冷静期及之后）发现仍有未使用权益，可联系人工客服提供注销凭证申请补发至新账号（限1次），超过90天不再受理。

## 1.6 投诉升级
对申诉结论不满意可升级至平台纠纷委员会（每周四线上听证），委员会由平台侧2人+用户代表1人+外聘顾问1人组成，听证结论为最终结论，全程录音存档。

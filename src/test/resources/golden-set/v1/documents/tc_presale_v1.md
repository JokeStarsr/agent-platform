# 电商平台预售定金政策（v1）

## 1.1 预售模式
预售订单支付两阶段：订金阶段（拍下并支付订金锁定名额）与尾款阶段（活动当日支付尾款）。订金标准为商品价格的10%-30%，以商品页标注为准。

## 1.2 订金规则
订金支付后进入锁定期，订金不可单独退还，需支付尾款或整单退款时一并退还。未支付尾款的订单，订金在尾款支付期结束后7个工作日内原路退回。

## 1.3 尾款支付
尾款支付时间以活动页面倒计时为准，逾期未支付的订单自动取消，订金按上条第2款退回。尾款支付可使用优惠券（以券面规则为准）与积分抵扣，订金金额不参与优惠计算。

## 1.4 退款政策
订金支付后、尾款支付前申请退款：订金全额退回。尾款支付后按正常退货流程处理，退款金额 = 实付（订金+尾款）- 金额分摊使用优惠。已发货预售订单按普通商品退货规则。

## 1.5 价格保护
预售订单享受价保：尾款支付日后30天内（含当日），若同商品同 SKU 发生降价，可申请差价返还，返还金额以优惠券形式发放至账户。订金阶段的价格变动不影响已付订金订单。

## 1.6 预售发货
预售商品发货时间以商品页"预计发货"为准，一般为尾款支付后3-15天。含预售的合单订单，预售商品到仓后单独发货，不等待现货商品一起发。

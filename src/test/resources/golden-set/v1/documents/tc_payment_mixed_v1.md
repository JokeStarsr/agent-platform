# 电商平台混合支付政策（v1）

## 1.1 混合支付组合
支持组合支付：余额+银行卡、余额+信用支付、优惠券抵扣+任意方式、积分抵扣+任意方式。不支持"银行卡A+银行卡B"双卡组合，支付页支持一键切换组合方案。

## 1.2 支付顺序
混合支付扣款顺序：账户余额优先 → 信用支付额度 → 银行卡/第三方渠道。积分与优惠券在计算阶段先行抵扣，不计入支付渠道顺序。

## 1.3 混合支付退款
混合支付订单退款按支付比例原路退回：余额部分退回余额账户（即时到账），银行卡部分退回原卡，信用支付部分冲抵账单。退款到账时效见退款时效政策1.2。

## 1.4 组合变更
待付款订单支持修改支付方式组合（如余额不足改全卡支付），修改后保留新一轮支付时限30分钟。已支付订单不可修改组合。

## 1.5 组合支付限额
混合支付总限额=各渠道限额之和，但不超过订单金额。任一渠道超额时支付失败并提示超额渠道，可调整组合后重新支付。

## 1.6 预授权与担保
部分大额订单（≥3000元）在支付时对银行卡执行预授权冻结，确认收货后解冻；预授权占用额度期间不影响该卡其他小额支付。

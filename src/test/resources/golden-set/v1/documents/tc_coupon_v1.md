# 电商平台优惠券政策（v1）

## 1.1 优惠券类型
平台优惠券分为：店铺券（限店铺使用）、平台券（全平台通用）、品类券（限指定类目）、新人券（新注册用户专属）。按形式分为满减券、折扣券（限品类支持）、无门槛券。

## 1.2 领取与使用规则
优惠券在商品详情页、店铺首页、"领券中心"领取，每个账户每类券领取数量以券面说明为准。使用时需满足券面消费门槛，仅限支付时抵扣商品金额，不包含运费和税费。

## 1.3 有效期规则
优惠券有效期以券面展示为准，一般7天至30天不等。大促券有效期覆盖活动全周期。过期券自动作废，不补发、不延期；因平台原因造成的误发券在回收说明中标注。

## 1.4 退券规则
订单全额退款且券已使用：若券在有效期内，退还同等面值券并延长有效期30天；若券已过期，退回的券按原有效期计算（即不延长）。部分退款不退券，退款金额按比例退回。

## 1.5 不可用场景
优惠券不可用于：礼品卡购买、虚拟商品（话费、会员充值）、预售定金、跨境商品、二手/拍卖商品。平台页面标注"不可用优惠券"的商品以支付页实际抵扣结果为准。

## 1.6 券风控
同一设备/同一收货地址/同一支付账户批量注册领取新人券属于套券行为，平台有权限制账号下单资格并追回已享受优惠。恶意套券金额较大的提交司法机关处理。

## 1.7 异常券处理
系统误发、重复发放的优惠券，平台有权在发放后48小时内收回，收回时已下单未支付的订单按原价支付，已支付订单按实际支付金额结算，不追溯差价。

# 电商平台优惠叠加政策（v1）

## 1.1 叠加层级
优惠计算顺序：单品直降 → 满减/满折活动 → 平台券 → 店铺券 → 会员折扣 → 积分抵扣。同级优惠互斥，跨级优惠可叠加。最终实付不得低于0元。

## 1.2 平台券与店铺券
平台券与店铺券可叠加使用，叠加顺序为先平台券后店铺券。两张同类型券（如两张平台满减券）不可同时使用，支付页自动选择对用户更优的一张。

## 1.3 会员折扣叠加
会员折扣与平台券可叠加；会员折扣与秒杀价、预售直降不可叠加（自动取更优）；积分抵扣可与会员折扣叠加，但不可与第三方发放的优惠码同时使用。

## 1.4 满减活动与券
店铺满减活动与店铺券互斥时，系统自动比较两种方案的优惠金额，默认执行优惠更大的方案。商品参加1元秒杀/0元购等极限活动时，不与其他任何优惠叠加。

## 1.5 叠加限额
单笔订单优惠叠加总额不超过订单商品金额的70%（虚拟商品不超过50%），超出部分自动裁剪。大促期间平台券可与官方满减叠加，享受双重优惠。

## 1.6 退款时优惠分摊
部分退款时，已使用的多级优惠按商品金额比例分摊到各商品上，退回金额 = 商品分摊实付金额。整单退款退回全部实付金额与运费。

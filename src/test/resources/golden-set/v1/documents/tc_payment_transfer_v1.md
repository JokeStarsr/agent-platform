# 电商平台对公转账支付政策（v1）

## 1.1 对公转账适用
企业采购订单支持对公转账支付，适用场景：单笔≥1万元的采购订单、需对公结算的单位订单。下单后选择"对公转账"生成专属付款码（附订单号），按提示金额转账到对公账户。

## 1.2 到账确认
对公转账需人工核账：工作日9:00-18:00转账，2小时内到账确认；其余时间次工作日12:00前确认。确认到账后订单自动流转发货，未确认前订单状态为"待汇款"。

## 1.3 转账金额误差
转账金额必须与订单金额一致，多转部分在订单完成后7个工作日内原路退回，少转部分需补足差额后才能发货。转账附言需填写付款码，未填附言可能导致核账延迟。

## 1.4 转账退款
对公转账订单退款默认退回原付款账户，到账时效3-7个工作日；需退回其他账户时提供盖章委托函，平台审核后10个工作日内处理。转账手续费（银行侧）不退。

## 1.5 对公账户信息
对公账户信息以支付页展示为准，平台不会通过电话/短信发送变更后的收款账户。收款账户变更需平台官网公告且公示≥7天，切勿向陌生账户转账。

## 1.6 大额企业采购
单笔50万元以上企业采购建议联系大客户经理开通企业采购通道，可享账期服务（30/60天授信，需资质审核：营业执照+近两期纳税证明），授信订单按期对账结算。

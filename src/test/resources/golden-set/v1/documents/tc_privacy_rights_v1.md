# 电商平台个人信息权利政策（v1）

## 1.1 查询权
用户可在"设置-个人信息导出"发起个人信息副本导出：内容覆盖个人资料、订单记录、浏览记录（脱敏版）。导出申请7个工作日内生成下载链接（保留7天），导出格式为JSON/CSV。

## 1.2 更正权
更正入口："我的-账户资料"。可自助更正：收货地址、联系电话、邮箱、昵称、性别（每季度1次）；需人工更正的：姓名（实名后按实名认证政策处理）、历史订单收货信息（订单完成后不可改，需联系商家协商）。

## 1.3 删除权
删除范围：浏览记录（点删除即清）、收货地址、账户内个人信息（完整删除走注销流程见退会注销条款）。法规要求保存的交易记录（订单/支付凭证保存期：交易信息5年）不可提前删除，仅在保存期满后自动清理。

## 1.4 携带权
个人信息携带：按监管要求，可再生数据集（昵称/头像/收货历史）支持一键导出至其他平台，导出模板与行业标准兼容（JSON Schema v1），处理时限7个工作日。

## 1.5 撤回同意
撤回营销同意：退订短信回复TD、App内"营销通知"开关、隐私设置"个性化推荐"开关。撤回不溯及既往已处理的同意；撤回后平台停止基于该处理目的的使用。

## 1.6 权利请求处理时限
权利请求（查询/更正/删除/携带/撤回/拒绝自动化决策）统一7个工作日内响应；复杂请求（多系统联合检索）经通知用户后最长延期至30日。无正当理由重复请求可收取合理工本费（10元/次）。

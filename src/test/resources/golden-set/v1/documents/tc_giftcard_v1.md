# 电商平台礼品卡政策（v1）

## 1.1 礼品卡类型
平台礼品卡分：电子礼品卡（APP购买，即买即发，卡密推送）与实体礼品卡（线上订购线下邮寄，可自选面值50/100/200/500/1000元）。分固定面值与可自定义充值面值两种。

## 1.2 绑定与使用
礼品卡需绑定至账户后使用：绑定入口"我的-礼品卡-绑定卡密"。绑定后卡内余额可支付全部订单（不可用于礼品卡自身购买），支持多卡叠加支付，卡余额不设有效期（但平台连续3年无动账且无法联系用户的情况下可依法上缴）。

## 1.3 购买规则
礼品卡购买支持企业批量采购（50张起，可开专票），个人购买单笔限10张。购买礼品卡不可使用优惠券与积分抵扣，不支持用礼品卡余额购买礼品卡。

## 1.4 退款与转让
礼品卡绑定后不可退现；未绑定的电子卡密，购买后7天内可申请退款（需未使用、未绑定）。礼品卡支持转赠（绑定前按卡密转移，绑定后不可转让）。余额退款至原购买支付渠道。

## 1.5 丢失与找回
卡被盗刷：绑定账户内余额变动可在"资金明细"申诉，核实非本人操作全额追回。卡密泄露被他人绑定的，提供购买凭证+绑定时间核对后转移余额至新卡。实体卡挂失需提供卡号。

## 1.6 有效期细则
固定面值卡有效期以卡面为准（一般自激活起3年）；自定义充值卡余额长期有效。临期卡余额支持"自动展期"设置（到期前30天内充值任意金额展期1年）。过期卡余额退回至原支付渠道（扣除5%手续费）。

# 电商平台会员跨场景权益政策（v1）

## 1.1 跨业务线权益
平台会员体系覆盖：电商购物、平台外卖（合作商家）、视频内容、云服务（合作）。同一等级跨线通用，消费额合并累计至月度等级判定。

## 1.2 积分互通
跨线积分通用：外卖积分与购物积分同池累计，兑换范围覆盖四个业务线。跨线消费积分倍率：购物1x、外卖0.5x、内容平台0.3x（V3以上1x）。

## 1.3 权益互斥
同一等级在四个业务线的同类权益（如免运费券）共享受益上限：每月合计不超过本线权益数量，跨线领取需在"我的-权益"选择领取目标线，已领权益不可转线。

## 1.4 等级迁移
跨月等级变化时，各线权益按下月新等级同步调整；降级当月旧等级权益（免运费券等）保留至月底，逾期作废不补。跨线消费未满整月不单独计算等级。

## 1.5 企业会员
企业团体采购（月采购额≥5万）可开通企业会员：等级V3起，支持将积分发放至员工个人账户（按员工手机号绑定），企业管理员可在后台查看积分发放明细。

## 1.6 附属卡会员
主卡会员可为家庭成员开附属卡（上限3张）：附属卡共享主卡等级，独立积分池（倍率1x），附属卡消费计入主卡月度等级贡献。

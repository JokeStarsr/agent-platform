# 电商平台发票抬头管理政策（v1）

## 1.1 抬头类型
支持个人抬头与企业抬头两类。个人抬头仅需填写姓名；企业抬头需提供单位名称与纳税人识别号，视地区要求补充开户行及账号信息。抬头类型一经选择不可随意切换为已开票金额两次以上。

## 1.2 抬头修改时限
未开票订单的抬头可随时在"发票中心"修改；已开票电子发票如需修改抬头，需先申请红冲（见发票红冲政策），红冲成功后重新提交开票申请，原发票信息保留存档供税务核对。

## 1.3 抬头一致性校验
开票抬头与实际付款人无需一致，可由他人代付后本人抬头开票。但企业专票的抬头必须与收货单位营业执照名称一致，否则无法通过税务系统校验，开票将被驳回并提示修改。

## 1.4 常用抬头保存
支持保存最多10个常用抬头，含默认抬头设置。企业抬头可上传营业执照自动识别公司信息，识别结果支持人工校验后保存。个人抬头支持快捷输入姓名与身份证号后4位辅助识别。

## 1.5 抬头信息变更影响
抬头变更不影响订单配送地址和售后流程。已开票订单的抬头变更需走发票红冲流程，红冲与原发票之间的差额需在后续开票中结清，平台不因抬头变更收取任何费用。

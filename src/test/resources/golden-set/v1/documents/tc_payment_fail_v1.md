# 电商平台支付失败与异常扣款政策（v1）

## 1.1 支付失败常见原因
支付失败原因：余额不足、卡片限额、银行风控拦截、短信验证超时、网络中断。支付失败不生成订单不扣款，可在"待付款订单"重新发起支付，系统对同一订单保留支付入口30分钟。

## 1.2 重复扣款处理
同一订单重复扣款（支付成功但页面未跳转）：系统15分钟内自动核对并原路退回多扣款项；超过15分钟未退回的，在"收入明细"发起申诉，平台24小时内核实处理。

## 1.3 支付成功订单未生成
扣款成功但订单未生成（超时异常）：系统自动识别"资金滞留单"并在2小时内自动补单或原路退款（自动判定场景，无需用户操作）；24小时后仍未处理的可在客服入口提交扣款凭证人工核对。

## 1.4 风控拦截
大额/异地/新设备支付触发风控时，需完成实人认证（人脸或短信+身份信息），认证通过后恢复支付。同一时间多渠道频繁支付被拦截均属风控正常流程，不代表账户异常。

## 1.5 第三方渠道状态
支付渠道（微信/支付宝/银行）系统维护时段可能短暂不可用，平台在支付页展示渠道维护公告。渠道侧故障引发的支付中断，订单状态保持"待付款"，恢复后重试即可。

## 1.6 争议款项申诉
对扣款有异议时，可在"我的-资金账户-交易明细"对单笔交易发起申诉，需提供：订单号、扣款渠道截图、时间。平台48小时内给出结论；与渠道存在分歧的，支持出具申诉函协助用户向银行渠道追索。

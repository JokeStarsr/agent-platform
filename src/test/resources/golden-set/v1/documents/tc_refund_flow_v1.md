# 电商平台退款时效政策（v1）

## 1.1 退款路径
退款默认原路返还：使用微信/支付宝支付退回对应账户，银行卡支付退回原卡，平台钱包余额支付退回余额账号。退款到账时间以支付渠道为准。

## 1.2 退款时效
商家同意退款后，平台即时发起退款：在线支付渠道一般实时至24小时内到账，银行卡渠道1-3个工作日，跨境支付7-15个工作日。退款进度可在"我的订单-退款详情"实时查看。

## 1.3 极速退款
符合以下条件自动极速退款（无需商家确认）：订单未发货且支付时间不超过24小时、会员V3及以上、历史退款率低于5%的优质用户。极速退款自申请受理后2小时内到账。

## 1.4 退款处理流程
退款申请提交后，商家需在48小时内处理；超时未处理系统自动同意退款。商家拒绝退款时需说明理由，用户可申请平台介入，平台在72小时内给出仲裁结论。

## 1.5 退款金额计算
退款金额 = 商品实付金额 + 分摊运费（整单退款全额退运费） - 已使用且过期的优惠券不再退回。多商品订单部分退款按商品实付金额比例分摊优惠与运费。

## 1.6 退款到账异常
超过承诺时效未到账时，可在退款详情页发起催退，平台核实后在24小时内响应。因支付渠道原因导致的长账期退款（超15个工作日），平台先行垫付并保留向渠道追偿权利。

# 电商平台会员权益细则（v1）

## 1.1 等级权益总览
会员等级权益（月度）：V1享基础积分倍率1x；V2享免运费券1张/月+2x积分；V3享免运费券3张/月+3x积分+专属客服；V4享免运费券5张/月+4x积分+专属客服+新品试购权+线下门店VIP通道。

## 1.2 免运费券
免运费券每月1日发放至"我的-权益中心"，当月有效，整月未用自动作废。免运费券适用于平台自营大件商品（上限减免30元运费），二手/跨境商品不可用。

## 1.3 专属客服
V3及以上享专属客服（在线工单优先+电话回访），服务时间延至23:00。专属客服对售后申请有优先流转权（处理时效较普通客服缩短50%）。

## 1.4 新品试购权
V4会员可提前24小时试用新品（"新品内测"专区），试用商品与正式售价一致，试用订单支持无理由退货。试购名额每月限量，先到先得。

## 1.5 会员日
每月8日会员日：会员全场95折（不含秒杀/特价）、积分翻倍、部分品类额外满减。会员日折扣与平台券叠加规则见优惠叠加政策1.3，与会员日常用折扣取更优。

## 1.6 线下权益
V3及以上会员可在平台合作线下门店享受权益：免费饮品、专属收银通道、停车券（每月2张），需在"我的-会员码"出示核销。线下权益随线上等级实时生效。

## 1.7 等级加速券
V2及以上每月可按需购买等级加速券（9.9元/张，限购5张），购买后当月消费额按1.5倍计入升级统计，加速券不退款不转赠。

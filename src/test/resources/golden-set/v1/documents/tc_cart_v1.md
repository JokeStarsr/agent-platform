# 电商平台购物车政策（v1）

## 1.1 购物车容量
购物车上限200件商品；单商品限购数量以商品页标注为准（一般20件）。商品加入购物车不锁库存，库存售罄后购物车内商品标注"缺货"，点击可跳转相似商品。

## 1.2 购物车价格
购物车价格展示当前售价，价格每日更新；结算时以支付页价格为准。商品降价后购物车价格自动更新，升价保持加入时价格快照（30分钟内有效）。

## 1.3 购物车优惠
购物车支持批量勾选结算：满减活动按勾选商品金额合计判断门槛，优惠券适用范围以券面规则为准。可对购物车内单个商品单独使用积分抵扣标记。

## 1.4 失效商品
购物车商品下架、规格变更、库存清零时自动置灰标注原因，勾选结算时被过滤并提示。失效商品保留30天（可一键删除），超期自动清理。

## 1.5 多端同步
购物车数据跨App/网页/小程序实时同步，同一账号同一时间登录多个设备以最后一次变更为准。未登录状态加购的商品在登录后自动并入购物车（限50件）。

## 1.6 购物车与收藏
收藏夹不占购物车容量；收藏商品的实时价保提醒（降价推送）每月限3条，可在"设置-降价提醒"调整频率。

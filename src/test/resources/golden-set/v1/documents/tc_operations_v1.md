# IT 运维问答知识库（示例，供 W9 新场景实测演示）

## 1. 账号解锁

员工账号被锁定后，请联系 IT 服务台（分机 8000）或在自助服务门户提交"账号解锁"工单。解锁通常 5 分钟内生效。

## 2. VPN 连接

公司 VPN 支持 Windows 与 macOS。连接前需确认已安装最新客户端并启用两步验证。首次连接请访问 vpn.company.com 下载客户端。连续 5 次密码错误将锁定账号 30 分钟。

## 3. 邮箱容量

员工邮箱配额默认 10GB。容量达到 90% 时会收到系统提醒；如需扩容请提交"邮箱扩容"工单，审批通过后扩容至 20GB。

## 4. 软件安装权限

普通员工默认无管理员安装权限。需要安装非标准软件时，提交软件安装申请，注明用途与安全评估，IT 审批后远程安装。

## 5. 数据备份

重要工作文件建议存放至网络共享盘（每日自动备份，保留 30 天）。本地桌面文件不在备份范围，重要文件请勿仅存本地。

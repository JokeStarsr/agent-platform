# 电商平台拼团政策（v1）

## 1.1 拼团模式
拼团商品按"开团-参团"模式购买：团长开团，邀请好友参团，成团人数以商品页标注为准（一般为2-5人）。成团后商品按拼团价发货；未成团自动退款。

## 1.2 成团时限
开团后24小时内需凑齐团员人数，超时未成团系统自动解散团并全额原路退款。团内成员可在"我的拼团"查看进度，支持一键生成分享海报邀请好友。

## 1.3 成团后规则
成团后团员不可主动退出，商品进入正常订单流程（发货/退款按普通订单规则）。若团长在成团前申请退款，该团自动解散，其余团员全部退款。

## 1.4 拼团价与优惠
拼团价是活动专属价，不再叠加店铺券与平台券，但会员折扣可叠加。拼团订单的拼团差价不计入发票金额，发票按实付金额开具。

## 1.5 拼团退款
拼团订单退款按普通订单规则执行，实际退款金额为团员各自实付金额。拼团进行中，单个团员退款即退出该团，成团人数不足时团自动解散并全员退款。

## 1.6 拼团限制
同一账号对同一拼团活动可开团1次、参团2次。同一收货地址/支付账户在同一活动中仅可参团5次，超出将被风控拦截。拼团商品库存共享，售罄后无法开团。

# 电商平台补开发票政策（v1）

## 1.1 补开适用范围
历史订单在确认收货后90天至12个月内可申请补开发票；超过12个月的订单原则上不支持补开，特殊情况下可在"发票中心"提交人工补开申请，由财务审核后3个工作日内答复。

## 1.2 补开流程
补开入口："我的-发票中心-历史订单补开"。选择需补开的订单（一次最多20笔）→ 填写抬头与开票信息 → 提交后普通发票即时生成，专票1-3个工作日。

## 1.3 补开金额限制
补开金额等于订单实付金额。若订单部分退款，仅支持补开退款后剩余实际支付部分；整单退款订单不可补开。运费已包含在实付金额内一并开票。

## 1.4 补开失败处理
补开失败常见原因：订单状态非"已完成"、订单已全额退款、超过补开时限。失败时平台提示具体原因并保留30天重试窗口，逾期需重新发起申请。

## 1.5 补开与红冲联动
补开发票发现金额或抬头有误时，按红冲流程处理：原发票红冲后重新开具正确发票，红冲无需退回纸质原票，电子票直接作废重开。

## 1.6 补开服务费
补开普通发票与电子专票不收取服务费；补开纸质专票需收取快递费10元/次，由平台代收并开具运费发票。平台自营与第三方卖家补开规则一致。

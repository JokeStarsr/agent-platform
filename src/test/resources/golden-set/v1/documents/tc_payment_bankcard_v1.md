# 电商平台银行卡支付政策（v1）

## 1.1 卡种支持
支持境内主流银行储蓄卡与信用卡（工农中建交、股份制银行、城商行以通道列表为准）。信用卡支付需开通网上支付功能且预留手机号与当前绑定一致。

## 1.2 支付限额
储蓄卡单笔限额：默认1万元（可至发卡行调高），日累计2万元；信用卡以发卡行风控为准，一般单笔2-5万元。限额受发卡行控制，平台无法上调，超限需分笔支付或更换卡种。

## 1.3 快捷支付
首次绑卡需短信验证+银行卡要素校验（卡号/姓名/身份证/手机号），绑定成功后可免密快捷支付。同一银行卡支持绑定3个不同平台账户，超出需解绑后重绑。

## 1.4 密码与安全
快捷支付已验证设备+支付密码双因子；更换设备首笔支付需重新短信验证。平台不会以任何形式索要银行卡密码与CVV，谨防电信诈骗。

## 1.5 卡被扣款错误
重复扣款或错误扣款：在订单支付页面核对"实付=应付"后，仍被重复扣款的订单，系统在24小时内自动原路退回多扣金额；银行卡扣款失败时支付不生成订单，原卡未被扣款即可重付。

## 1.6 银行卡注销与挂失
银行卡注销/挂失后支付失败，需在"我的-支付方式"删除旧卡重新绑定新卡；已绑定期间的退款按原路退回至原卡（卡片已注销时，由发卡行转至新卡或用户提供他行账户，7个工作日内处理）。

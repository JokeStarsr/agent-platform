# 电商平台企业专票政策（v1）

## 1.1 专票申请条件
企业增值税一般纳税人可申请增值税专用发票，需在"发票中心"完成企业认证：上传营业执照、填写纳税人识别号、选择税率（现行6%或13%，按商品类目自动匹配）。小规模纳税人仅可开具普通发票。

## 1.2 专票开具流程
企业专票申请路径："我的-发票中心-专票申请"。购货方信息需与营业执照完全一致，平台在2个工作日内完成开票校验，校验通过后1-3个工作日内开具，支持下载PDF或快递寄送纸质票。

## 1.3 专票税点说明
专票税点由税务规定，具体可见票面税率。开具专票的订单不再支持开具普票；已开普票的订单如需改开专票，先红冲普票（需采购方配合），再重新申请专票。

## 1.4 专票邮寄
电子专票开具后推送至企业邮箱；纸质专票默认顺丰寄出，运费平台承担。纸质专票签收后请核对票面信息，30天内未提出异议视为票面无误。

## 1.5 专票丢失处理
电子专票可随时重新下载；纸质专票丢失需企业出具书面说明函并加盖公章，平台在核对订单与开票记录后，提供发票信息复印件或COA证明，不重新开具原票。

## 1.6 专票风控
同一企业纳税人识别号单日申请专票超过50笔，或单笔开票金额超过5万元，触发风控人工审核，审核材料包括采购合同或审批单，审核周期3-5个工作日。
